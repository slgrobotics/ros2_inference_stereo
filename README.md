# ROS2 Object Recognition and Stereo Vision on Raspberry 5

A ROS2 node to perform object recognition and stereo-to-PointCloud2 publishing on a Raspberry Pi 5

This project was inspired by excellent work by Eryk Pawełek - with much code borrowing from his [repo](https://github.com/erykpawelek/ros2_vision_playground).
